# LinkedIn Post Draft - eiDotter v0.3.0

## Post

Shipped eiDotter v0.3.0 - a DOS-themed React component library with authentic CGA terminal aesthetics.

**What's new:**
- 16 components (Badge, Breadcrumb, Switch, Tabs, TimelineNode, RetroEffects)
- Full accessibility audit with axe-core (WCAG 2.1 AA compliant)
- Tailwind CSS preset for using tokens without React
- Custom domain: storybook.eidotter.com

**Why DOS aesthetics in 2025?**

It's not retro for retro's sake. The DOS terminal represents control, clarity, and focused interaction. No distractions. Just you and the machine.

Building this has been a masterclass in:
- Design token pipelines (Style Dictionary v4 + DTCG format)
- Accessibility testing at scale
- Component API design

Open source: https://github.com/CinimoDY/eiDotter
Live Storybook: https://storybook.eidotter.com
