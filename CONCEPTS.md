# Concepts

Shared domain vocabulary for this project — entities, named processes, and status concepts with project-specific meaning. Seeded with core domain vocabulary, then accretes as ce-compound and ce-compound-refresh process learnings; direct edits are fine. Glossary only, not a spec or catch-all.

---

## Content Provenance

### Provenance Marker
A CSS-driven signal on a prose element indicating that the text is AI-drafted and has not yet been revised by a human author. The canonical form is the HTML attribute `data-provenance="ai-draft"` placed by consumers (devjournal, SSG pipelines) on `<p>`, `<li>`, and `<blockquote>` elements after a per-paragraph diff against the AI baseline. The visual treatment (a theme-aware magenta gradient clipped to the text) is applied entirely by CSS; no JavaScript or React component is required. Consumers may also apply `data-ai-block` to a wrapper element to mark all prose descendants at once.

### AI-Draft State
The initial lifecycle state of a prose paragraph generated by an AI workflow. A paragraph in AI-draft state carries the provenance marker and renders with the gradient treatment. Transition to the revised state happens when the author rewrites the paragraph in their own voice and removes the `data-provenance` attribute (or runs the `mark-provenance.mjs` script, which measures drift from the AI baseline and strips the attribute when the paragraph diverges sufficiently). A paragraph with no `data-provenance` attribute is implicitly revised.
*Avoid:* "unrevised", "AI text" (too broad — AIText is a specific inline component), "stamped" (refers to the act of marking, not the state)

### Block Mode
The whole-section variant of provenance marking, activated by placing `data-ai-block` on a container element (`<article>`, `<section>`, `<main>`). The CSS rule selects all prose descendants (`h1`–`h6`, `p`, `li`, `blockquote`, `strong`, `em`) and applies the gradient marker without requiring individual paragraph attributes. Used on non-MDX surfaces where stamping individual elements is impractical. Descendants can opt out via `data-ai-skip="true"`.

### AIText
The ergonomic React shortcut for the provenance marker API. Renders a `<span data-provenance="ai-draft">` with a screen-reader-accessible "AI-assisted:" prefix and a default title attribute. Intended for marking a single phrase within otherwise-human prose in hand-authored MDX. For per-paragraph bulk marking, prefer the raw `data-provenance="ai-draft"` attribute directly on the prose element.
*Avoid:* "AIText component" when referring to the attribute system generally — AIText is one consumer of the attribute API, not the API itself.
