# Upgrading to eidotter 0.44.0

From 0.43.x. Coming from older versions, read [0.41.0.md](./0.41.0.md) and
[0.43.0.md](./0.43.0.md) first.

0.44.0 fixes what the first 0.43 adoptions found. Four changes are visible
without touching your code; one prop is new.

## Who must act

- Apps that mark AI-drafted content (`data-ai-block`, `data-provenance="ai-draft"`): check your headings (section 2).
- Apps that render `PageShell`: give the page its own background and font if it relied on PageShell's (section 3).
- Everyone else: bump and check the Header and the ⌘K palette at phone width.

## 1. How to bump

```bash
npm install eidotter@^0.44.0
npm ls eidotter   # 0.44.0 or later
```

Commit the lockfile.

## 2. Visible: headings are never marked as AI-drafted

**What changed.** `provenance.css` used to paint `h1` to `h6` with the
magenta AI-draft gradient inside a `data-ai-block` wrapper, and on a heading
that carried `data-provenance="ai-draft"` itself. Headings now keep their
normal colour in both cases. Only prose (paragraphs, list items, quotes and
their emphasis) shows the marker. A heading nested inside a marked container
(a `<div data-provenance="ai-draft">`) gets a readable colour back: your own
heading colour if you set one, otherwise the body text colour.

**How to find it.** Open a page wrapped in `data-ai-block`. Page, section and
card titles that were magenta are now in your heading colour.

**What to do.** Nothing, unless your own CSS paints headings with the
gradient. Search your styles for `data-ai-block` or `ai-draft` rules that
target `h1`–`h6` and remove them.

## 3. Visible: PageShell inherits the page

**What changed.** `PageShell` no longer paints `background-primary` and no
longer sets `font-family`, `font-size` or `line-height`. Your page's own
background (a CRT tint, `RetroEffects`) and body font now show through. Its
column no longer grows past the viewport when a child is wide (a Header with an
`end` slot, a Footer), and with `contentId` the content gets `tabIndex={-1}`,
so a skip link moves keyboard focus.

**What to do.** If your page had no background or font of its own and relied
on PageShell's, set them on `body` or put a class on the shell:

```tsx
<PageShell className="my-page" …>
```

```css
.my-page {
  background-color: var(--color-semantic-background-primary);
  font-family: var(--typography-font-family-body), var(--typography-font-family-fallback);
  line-height: 1.5;
}
```

**How to verify.** At 320px and 390px, `document.documentElement.scrollWidth`
equals the viewport width.

## 4. Visible: a one-word Header brand never splits

**What changed.** 0.43.0 floored the brand at about 8 tracked characters and
broke a longer single word mid-word ("DMNC.TEC / H" at 320px). The floor is
now the brand's longest word: words break only at spaces, and once the brand is
at its floor the `end` slot clips instead. A single word wider than the whole
row (about 11 tracked characters beside the lockup icon and MENU at 320px)
overflows.

**What to do.** Check the Header at 320px. If the `end` slot content is cut
off, hide it below a width you choose or move it into the menu. If the brand
word itself is too long, shorten `brandName` or use `brandCollapse="mark"`.

## 5. Visible: CmdPalette

- The search input is focused as the palette opens, in the same tap or
  keypress, so phones raise the keyboard straight away.
- The blinking `_` in the `JUMP TO` strip is gone (it looked like an input).
  The `eidotter-cmdpal__blink` class no longer exists; delete any CSS that
  targets it.

## 6. New: LegalPage `embedded`

```tsx
<PageShell header={…} footer={…}>
  <LegalPage embedded title="Impressum" date="Stand: Oktober 2026">
    <ImpressumAddress />
  </LegalPage>
</PageShell>
```

`embedded` drops LegalPage's own 720px column, centring, padding, min-height,
background and font, and start-aligns the hero without the rule under it, so
the page shares your site's left edge. Without it, LegalPage renders as before.

## Checklist

- [ ] `npm install eidotter@^0.44.0`; `npm ls eidotter` shows 0.44.0 or later. Commit the lockfile.
- [ ] Pages with `data-ai-block`: titles are in your heading colour; remove any own CSS that painted headings (section 2).
- [ ] Pages on `PageShell`: background and font come from your page; no sideways scroll at 320/390 (section 3).
- [ ] Header at 320px: brand on whole words, nothing important lost from the `end` slot (section 4).
- [ ] Delete CSS targeting `eidotter-cmdpal__blink`, if any (section 5).
- [ ] Optional: `LegalPage embedded` inside your page column (section 6).
