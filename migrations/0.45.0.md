# Upgrading to eidotter 0.45.0

From 0.44.x. Coming from older versions, read the earlier guides first
([0.41.0](./0.41.0.md), [0.43.0](./0.43.0.md), [0.44.0](./0.44.0.md)).

0.45.0 adds one shared theme control and changes how the Header brand behaves
on narrow screens.

## Who must act

- Apps with a long `Header` brand on phones: check the header at 320px and 390px (section 2).
- Apps that put theme or display switches in the Header `end` slot: replace them with `DisplayMenu` (section 4).
- Everyone else: bump and glance at the Switch labels on the light theme (section 3).

## 1. How to bump

```bash
npm install eidotter@^0.45.0
npm ls eidotter   # 0.45.0 or later
```

Commit the lockfile.

## 2. Visible: the brand title never wraps

**What changed.** 0.43 let a long brand wrap onto a second line. Now the
title always stays whole on one line, never wrapped and never cut short with
"…". When the row is too tight, a lockup or mark brand drops its logo icon
first, then the `end` slot clips. The MENU trigger never shrinks. Below 480px,
the gaps around the right-hand group are 8px instead of 16px.

**How to find it.** At 320px a title like "DMNC.TECH" or "EIDOTTER" next to
an end control and MENU now shows without its icon. A two-word title that
used to wrap is on one line.

**What to do.**

- Nothing, if the title fits on one line beside MENU.
- A title wider than the whole row (about 11 tracked characters plus MENU at
  320px) now overflows the page. Shorten `brandName`, or use
  `brandCollapse="mark"` to show only the icon below 480px.
- CSS that relied on the icon coming first in the DOM: the name now comes
  first (`.eidotter-header__brand-name`, then `.eidotter-header__brand-icon`);
  the link lays them out in reverse, so it looks the same.

**How to verify.** At 320px and 390px the title is on one line, the page does
not scroll sideways, and controls in the `end` slot are whole.

## 3. Visible: Switch labels follow the theme

The `Switch` label used the raw amber colour, which failed contrast on the
light theme. It now uses the brand text colour: unchanged on amber, dark
amber on light, ink on amber-paper. The label has a class,
`eidotter-switch__label`, if you need to style it.

## 4. New: DisplayMenu, the one theme control

Put one `DisplayMenu` in the Header `end` slot instead of switches side by
side. It opens a small panel with one switch per option. Your app keeps the
state and applies it (for example `data-theme` on `<html>`).

```tsx
import { Header, DisplayMenu } from 'eidotter';

const [dos, setDos] = useState(true);
const [paper, setPaper] = useState(false);

<Header
  brandName="Example"
  items={items}
  end={
    <DisplayMenu
      items={[
        { id: 'dos', label: 'DOS', checked: dos, onChange: setDos },
        {
          id: 'paper', label: 'Paper', checked: dos && paper, onChange: setPaper,
          disabled: !dos, hint: dos ? undefined : 'Needs DOS on',
        },
      ]}
    />
  }
/>
```

- `label` (default `'Display'`) names the button and the panel.
- `labelDisplay`: `'responsive'` (default, icon only below 640px), `'icon'`, `'label'`.
- `placement`: `'bottom end'` (default), `'bottom start'`, `'bottom'`. `defaultOpen` for docs.
- Escape or a click outside closes the panel and returns focus to the button.
- It is a client component (`'use client'`); in a Next.js server component,
  render it from a client wrapper.

## 5. Fixed

- A heading inside a marked list item, paragraph or quote in `data-ai-block`
  mode is no longer painted magenta.
- `LegalPage` body links wrap long URLs instead of widening the page.

## Checklist

- [ ] `npm install eidotter@^0.45.0`; `npm ls eidotter` shows 0.45.0 or later. Commit the lockfile.
- [ ] Header at 320px and 390px: title on one line, no sideways scroll, end controls whole (section 2).
- [ ] Switch labels readable on every theme you offer (section 3).
- [ ] Replace side-by-side theme switches in the header with one `DisplayMenu` (section 4).
- [ ] Drop any site CSS that wrapped long LegalPage links or recoloured headings in AI-marked lists (section 5).
