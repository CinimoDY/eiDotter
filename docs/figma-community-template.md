# eiDotter - DOS-Themed Design System

A modern design system that brings the nostalgic MS-DOS/286 aesthetic to the web. Perfect for retro-themed applications, games, or any project wanting that classic computing feel.

## 🎨 Design Tokens

### Colors
- CGA 16-color palette
- Semantic color tokens for backgrounds, text, and interactions
- Authentic DOS color combinations

### Typography
- IBM PC BIOS font
- Monospace-based type scale
- Text styles for different UI elements

### Spacing
- 8px grid system
- DOS-style padding and margins
- Component-specific spacing

## 🧱 Components

### Basic Elements
- Buttons (Primary, Secondary, Danger)
- Text inputs
- Checkboxes and Radio buttons
- Progress bars

### Containers
- Windows
- Dialog boxes
- Menu bars
- Status bars

### Navigation
- Command prompts
- Menu items
- Tabs
- Scrollbars

## 📖 Usage Guidelines

1. **Installation**
   - Download the Figma library
   - Add to your project
   - Connect with the React component library

2. **Best Practices**
   - Use authentic CGA colors
   - Maintain pixel-perfect edges
   - Follow DOS-era interaction patterns
   - Keep text uppercase for system elements

3. **Accessibility**
   - High contrast color combinations
   - Keyboard navigation support
   - Clear focus states
   - Screen reader considerations
