    WHAT TO FEEL FOR
    1. Anchoring: with "Becomes the border" on, raise Item border to 3 px. The arm tip should stay exactly as thick as the border and run into it, never across the label. Compare with "Near corner", which is what you saw in round one.
    2. Choose the Column layout, then "Trunk and branch". One amber line goes down and each coloured branch leaves it. In this model the arm grows along its path, tip first, the way a hypha extends. Try Row as well: the trunk turns horizontal.
    3. With the trunk on, hover an item. Can you still tell at once which branch is whose? All the colour is now in the last short stretch.
    4. Open and close the menu a few times while changing the two Close dials. Pulling back starts critically damped (1.00), so nothing bounces inside the yolk.
    5. Set "Short arms are faster" to 0, then 1, in the Arc layout and replay. At 0 every arm takes the same time whatever its length.
    6. Round three: choose "Throw, then comb" in the Column layout and press REPLAY FLING. The items are thrown out on ropes, then the ropes pull straight into the comb. On close they go slack again and are reeled in. Does the playful start earn its place before the logical finish?

    Keyboard: the yolk is a button. Tab or arrow keys move between items, Enter selects, Escape closes. The arms are drawn on a canvas that assistive technology ignores; the items are real buttons.
