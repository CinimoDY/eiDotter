# Rizonode prototypes

Throwaway interaction prototypes for the rizonode (working name: rhizomorph): the yolk at the
top left of a page whose arms carry the menu items out and hold them.

Each file is one self-contained HTML page with no build step. Open it in a browser.

| File | What it explores |
|---|---|
| `arm-lab.html` | How an arm moves and where it meets its item: spring Bézier, Verlet rope, trunk and branch, and a rope throw that settles into the comb. Dials for the open and close springs, colour mixing and anchoring. |
| `nesting-lab.html` | Nested levels: the line runs through an opened item and on to its children. Sibling behaviour (stay, fade, leave), keyboard model, going back. Menu entries are made up. |

These are sketches for judging feel, not components. Nothing in them is decided, they do not use
the Eidotter tokens or components, and they are not part of the published package. Git history
is the version record: edit a file in place and commit.
