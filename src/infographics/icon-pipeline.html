Design Decisions
Why pixelarticons?
MIT licensed (no sublicense issues), authentic DOS pixel-art aesthetic that matches eidotter's design language, ~480 base icons to choose from. Previously used @untitledui-pro/icons but removed for license reasons — UTI Pro is not sublicensable.
Why curate to just 12?
Constrained vocabulary prevents icon sprawl. Each name has clear semantics tied to eidotter's component system: status indicators (Info, Warning, Error), actions (Check, Close, Add), navigation (Chevron Up/Down), and window chrome (App, Cancel, Fullscreen).
Why a custom PixelX?
pixelarticons v2 has no standalone X/close glyph. Their Cancel component renders a slashed circle, which doesn't match the expected "close" affordance. We hand-drew a pixel-art X matching their grid system (2×2 unit pixels on 24×24 viewBox).
The Mapping (simplified)

const ICON_MAP = {
  'Info':         InfoBox,
  'Warning':      WarningDiamond,
  'Error':        SquareAlert,
  'Done':         Check,
  'Check':        Check,              // shared glyph
  'Close':        PixelX,             // custom SVG
  'Chevron Up':   ChevronUp,
  'Chevron Down': ChevronDown,
  'App':          WindowFrame,        // terminal icon
  'Cancel':       Minus,              // window minimize
  'Fullscreen':   Expand,
  'Add':          Plus,
} satisfies Record<string, PixelIcon>;
