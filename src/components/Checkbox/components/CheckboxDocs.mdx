# Checkbox

DOS-styled boolean toggle using DOS bracket notation `[X]` with phosphor glow.

The Checkbox replaces the native browser checkbox with a text-based DOS representation.
Unchecked renders as `[ ]` and checked renders as `[X]` with an accent-colored phosphor
text-shadow glow. It works controlled or uncontrolled.

> **Interactive demos**: See the [Checkbox stories](/story/components-checkbox--all-states) for live interactive examples.

## Display

The checkbox uses pure CSS `::before` pseudo-elements to render DOS bracket notation:

| State | Display | Color |
|-------|---------|-------|
| **Unchecked** | `[ ]` | `--color-semantic-text-primary` (light gray) |
| **Checked** | `[X]` | `--color-semantic-text-accent` (amber) + phosphor glow |

```tsx
<Checkbox label="Unchecked option" />
<Checkbox label="Checked option" defaultChecked />
```

## States

### Default (unchecked)

Displays `[ ]` in the primary text color. The label inherits the parent text color.

### Checked

Displays `[X]` in accent color with a `text-shadow: 0 0 4px` phosphor glow.

### Hover

When hovered (and not disabled), the box text shifts to `--color-semantic-text-brand-bright`. This applies to both checked and unchecked states.

### Disabled

Reduced opacity (0.6) with `not-allowed` cursor. Both the box and label use
`--color-semantic-text-disabled` color. The phosphor glow is suppressed in disabled+checked state.

```tsx
<Checkbox label="Disabled" disabled />
<Checkbox label="Disabled and checked" defaultChecked disabled />
```

## Controlled vs uncontrolled

### Controlled

Pass `checked` and `onChange` to keep the state in the parent:

```tsx
const [isEnabled, setIsEnabled] = useState(false);

<Checkbox
  label="Enable feature"
  checked={isEnabled}
  onChange={(checked) => setIsEnabled(checked)}
/>
```

### Uncontrolled

Use `defaultChecked` to set the initial state and let the checkbox manage itself:

```tsx
<Checkbox label="Remember me" defaultChecked />
```

## Form usage

Pass `name` and `value` for HTML form submission:

```tsx
<form>
  <Checkbox name="terms" value="accepted" label="I accept the terms" />
  <Checkbox name="newsletter" value="yes" label="Subscribe to newsletter" />
</form>
```

## Accessibility

- **Focus visible**: 2px solid outline with 2px offset on the box element, using `--color-semantic-border-focus`
- **High contrast**: Box gets bold weight (700), label gets semi-bold (600), focus outline widens to 3px via `prefers-contrast: high`
- **Reduced motion**: Color transition on box element disabled via `prefers-reduced-motion: reduce`
- **ARIA**: Native `<input type="checkbox">` with `aria-label` falling back to `label` text
- **Keyboard**: the native checkbox is visually hidden but stays focusable
- **Label**: Clicking the label text toggles the checkbox (wrapped in `<label>` element)

## API reference

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `checked` | `boolean` | — | Controlled checked state |
| `defaultChecked` | `boolean` | — | Initial checked state for uncontrolled usage |
| `onChange` | `(checked: boolean) => void` | — | Callback fired when checked state changes |
| `label` | `string` | — | Visible label text displayed next to the checkbox |
| `disabled` | `boolean` | `false` | Disables interaction and dims appearance |
| `name` | `string` | — | Name attribute for HTML form submission |
| `value` | `string` | — | Value attribute for HTML form submission |
| `className` | `string` | `''` | Additional CSS classes |
| `aria-label` | `string` | — | Accessible label override (defaults to `label` text) |

## Design tokens used

| Token | Purpose |
|-------|---------|
| `--color-semantic-text-primary` | Unchecked box and default label color |
| `--color-semantic-text-accent` | Checked `[X]` color and phosphor glow |
| `--color-semantic-text-brand-bright` | Hover state box color |
| `--color-semantic-text-disabled` | Disabled state box and label color |
| `--color-semantic-border-focus` | Focus outline ring |
| `--duration-fast` | Box color transition (100ms) |
| `--spacing-2` | Gap between box and label |
| `--typography-font-family-primary` | DOS font family |
| `--typography-font-family-fallback` | Fallback font family |
| `--typography-font-size-text-md` | Base font size |
