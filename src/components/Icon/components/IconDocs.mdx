# Icon

SVG icon component backed by [`pixelarticons`](https://github.com/halfmage/pixelarticons) (MIT licensed), in a DOS pixel-art style.

The Icon component wraps pixelarticons React components behind one eidotter API.
Icons inherit the parent's `color` by default via `currentColor`, so they follow
the theme. The pixel-art glyphs need no further styling.

> **Interactive demos**: See the [Icon stories](/story/components-icon--default) for live interactive examples.

## Available icons

| Name | Description | pixelarticons source |
|------|-------------|----------------------|
| `Info` | Information marker | `InfoBox` |
| `Warning` | Alert diamond | `WarningDiamond` |
| `Error` | Alert square | `SquareAlert` |
| `Done` / `Check` | Checkmark | `Check` |
| `Close` | Custom pixel-art ✕ mark | custom `PixelX` |
| `Chevron Up` | Chevron pointing up | `ChevronUp` |
| `Chevron Down` | Chevron pointing down | `ChevronDown` |
| `Chevron Left` | Chevron pointing left (Lightbox prev) | `ChevronLeft` |
| `Chevron Right` | Chevron pointing right (Lightbox next) | `ChevronRight` |
| `App` | DOS window frame | `WindowFrame` |
| `Cancel` | Minus — Terminal minimize control | `Minus` |
| `Fullscreen` | Expand — Terminal maximize control | `Expand` |
| `Add` | Plus | `Plus` |

> **Visual note on `Close`:** pixelarticons v2 has no standalone X/close glyph, so `Close` renders a custom pixel-art ✕ mark (the `PixelX` component, defined inline in `Icon.tsx`). Visually it renders as a pixel-grid diagonal cross, not the slashed circle that the pixelarticons `Cancel` component would produce.

> **Visual note on `Cancel`:** despite the name, this renders a minus glyph intended for the Terminal window's minimize control. It is **not** an abort/cancel action. Use `Close` for dismissal. A future release may rename `Cancel` → `Minimize` for clarity.

## Sizes

| Size | Dimensions | Use Case |
|------|-----------|----------|
| `L` (default) | 56 x 56px | Hero icons, feature callouts |
| `S` | 24 x 24px | Inline icons, buttons, labels |

```tsx
<Icon name="Warning" size="L" />
<Icon name="Close" size="S" />
```

## Color override

Icons inherit `currentColor` from their parent by default. Use the `color` prop
to override with a specific token:

```tsx
{/* Inherits parent color */}
<Icon name="Check" />

{/* Explicit color override */}
<Icon name="Warning" color="var(--color-cga-bright-red)" />
<Icon name="Info" color="var(--color-semantic-text-accent)" />
```

## Interactive icons

Add `role="button"` and `onClick` to make icons interactive:

```tsx
<Icon
  name="Close"
  size="S"
  role="button"
  onClick={() => handleClose()}
/>
```

## Accessibility

- **ARIA label**: Each icon has `aria-label="{name} icon"` by default
- **Custom label**: Pass `aria-label` prop to override
- **Interactive icons**: `role="button"` adds keyboard and pointer semantics
- **High contrast**: Interactive icons gain a 3px focus outline via `prefers-contrast: high`
- **Color inheritance**: Uses `currentColor` so icons adapt to parent text color

## API reference

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `name` | `IconName` | — | Icon name (required) |
| `size` | `'L' \| 'S'` | `'L'` | Icon dimensions (56px or 24px) |
| `color` | `string` | — | CSS color override (inherits `currentColor` if omitted) |
| `role` | `'button'` | — | Sets interactive icon behavior |
| `onClick` | `() => void` | — | Click handler |
| `className` | `string` | `''` | Additional CSS classes |
| `aria-label` | `string` | `'{name} icon'` | Accessible label override |
