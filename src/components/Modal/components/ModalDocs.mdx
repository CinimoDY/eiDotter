# Modal

DOS-styled dialog built on the **DosDialog** shell (DMNC-1592), the same chrome as CmdPalette and Lightbox.

React Aria `ModalOverlay > Modal > Dialog` (via DosDialog) handles the focus trap, scroll lock,
Escape and backdrop dismissal, and portals to `document.body`. The title sits in the amber title
strip (dark, yellow title, dim-amber rule) with the Close icon at its end; the footer keeps its 1px top rule.

> **Interactive demos**: See the [Modal stories](/story/components-modal--default) for live interactive examples.

## Anatomy

The Modal renders through DosDialog; its parts carry the shell's stable classes plus Modal's own:

| Element | Class | Purpose |
|---------|-------|---------|
| **Container** | `eidotter-dialog__container` + `eidotter-modal__container` | Brand border, amber glow, square corners |
| **Title strip** | `eidotter-dialog__head` | Dark strip: `▸` marker, yellow `<h2>` title, close control, dim-amber rule |
| **Close** | `eidotter-modal__close` | Close control in the strip end slot |
| **Body** | `eidotter-dialog__body` > `eidotter-modal__body` | Scrollable content area |
| **Footer** | `eidotter-dialog__footer` > `eidotter-modal__footer` | Optional right-aligned actions above a 1px rule |

```tsx
<Modal
  isOpen={isOpen}
  onClose={() => setIsOpen(false)}
  title="Confirm Action"
  footer={
    <>
      <Button variant="ghost">Cancel</Button>
      <Button variant="primary">Confirm</Button>
    </>
  }
>
  <p>Are you sure you want to proceed?</p>
</Modal>
```

## States

### Open

When `isOpen` becomes `true`, the panel pops in with the shared `eidotter-pop-in` keyframe
(scale 0.8 to 1 + opacity, 150ms: the CRT turn-on) while the scrim fades in. Reduced motion skips both.

### Closed

When `isOpen` becomes `false`, the panel plays `eidotter-pop-out` (150ms) and unmounts.
The `onOpenChange` callback fires on every state transition.

### Backdrop

Clicking the scrim closes the modal unless `isDismissable={false}`. The scrim uses
`--effects-overlay` with a 2px backdrop blur.

## Interaction Design

### Motion

Keyframes live in `src/styles/keyframes.css` (shared by every overlay):

```css
@keyframes eidotter-pop-in {
  from { opacity: 0; transform: scale(0.8); }
  to   { opacity: 1; transform: scale(1); }
}
```

### Close Mechanisms

Three ways to dismiss the modal:
1. **Escape key** - React Aria dismissal, fires `onClose` / `onOpenChange(false)`
2. **Backdrop click** - Clicking outside the container
3. **Close button** - Icon button in the title strip with `aria-label="Close modal"`

## Common Patterns

### Confirmation Dialog

```tsx
<Modal
  isOpen={isOpen}
  onClose={handleClose}
  title="Delete Item"
  footer={
    <>
      <Button variant="ghost" onClick={handleClose}>Cancel</Button>
      <Button variant="primary" onClick={handleDelete}>Delete</Button>
    </>
  }
>
  <p>Are you sure you want to delete this item? This action cannot be undone.</p>
</Modal>
```

### Form Modal

```tsx
<Modal
  isOpen={isOpen}
  onClose={handleClose}
  title="Create New Project"
  footer={
    <>
      <Button variant="ghost" onClick={handleClose}>Cancel</Button>
      <Button variant="primary" onClick={handleSubmit}>Create</Button>
    </>
  }
>
  <form>
    <Input placeholder="Project name" />
  </form>
</Modal>
```

## Accessibility

- **Focus trapping**: React Aria (via DosDialog) traps focus and locks page scroll
- **Escape to close**: React Aria dismissal handling
- **ARIA**: the dialog is named by `aria-label={title}`; the title also renders as an `<h2>` in the strip
- **Close button**: Has `aria-label="Close modal"` for screen readers
- **Focus visible**: Close button shows 2px solid outline on focus with 2px offset
- **High contrast**: Container border widens to 3px via `prefers-contrast: high`
- **Reduced motion**: All animations disabled via `prefers-reduced-motion: reduce`
- **Portal**: Rendered into `document.body` to avoid z-index stacking issues

## API Reference

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `isOpen` | `boolean` | — | Whether the modal is open (required) |
| `onClose` | `() => void` | — | Called when modal should close (required) |
| `onOpenChange` | `(isOpen: boolean) => void` | — | Called when open state transitions |
| `title` | `string` | — | Modal title, required for accessibility |
| `children` | `ReactNode` | — | Modal body content |
| `footer` | `ReactNode` | — | Footer content, typically action buttons |
| `size` | `'sm' \| 'md' \| 'lg' \| 'full'` | `'md'` | Shared DosDialog width map (sm 24rem, md 30rem, lg 40rem, full) |
| `isDismissable` | `boolean` | `true` | Close on scrim click (Escape and the close button always close) |
| `className` | `string` | — | Extra classes on the dialog container |
