# Button

DOS-styled action trigger with CRT phosphor interaction states.

The Button has four variants mapped to action intent. It uses CGA colors and phosphor
glow animations modeled on a cold CRT monitor warming up.

> **Interactive demos**: See the [Button stories](/story/components-button--all-variants) for live interactive examples.

## Variants

Each variant maps to a semantic role:

| Variant | Role | Example |
|---------|------|---------|
| **Primary** | Main action, destructive confirm | Save, Delete, Submit |
| **Secondary** | Supporting action | Cancel, Back, Reset |
| **Ghost** | Tertiary / low-emphasis | Settings, More options |
| **Link** | Navigation, inline action | Learn more, View details |

```tsx
<Button variant="primary">Save Changes</Button>
<Button variant="secondary">Cancel</Button>
<Button variant="ghost">Settings</Button>
<Button variant="link">Learn more</Button>
```

## States

### Disabled

Reduced opacity (0.6), `not-allowed` cursor. Background forced to secondary,
text to disabled color. All variants share the same disabled appearance.

### Loading

Displays a blinking block cursor (`█`) alongside dimmed content text.
The button is disabled while loading. It suppresses clicks and sets
`aria-disabled`.

### Full width

Stretches to fill container width. Use it in modals, forms, and mobile layouts.

```tsx
<Button fullWidth>Full Width Button</Button>
```

## Interaction design

The primary button layers several CRT phosphor animations:

### Rest state
No glow and no shadows (cold phosphor).

### Hover: phosphor warm-up
A 3-layer box-shadow bloom builds over 400ms (`--duration-slow`):

```css
box-shadow:
  0 0 8px 0 var(--color-cga-amber-glow),    /* inner core */
  0 0 20px 2px var(--effects-phosphor-glow), /* mid bloom */
  0 0 40px 4px var(--effects-bloom-outer);   /* outer halo */
```

Text gains a `text-shadow` glow. The button does not change size, because the
bloom is all box-shadow.

### Active: steady energy
Background brightens to `--color-cga-amber-bright`. Glow intensifies.
A scanline overlay (`::after` pseudo-element) scrolls down once every 4s,
like a CRT scan refresh.

### Hover: phosphor warmup flicker
On hover entry, a `phosphor-warmup` keyframe plays once (400ms). It simulates
CRT phosphor ignition: a brightness spike → overcorrection dip → secondary
excitation → settle. It runs at the same time as the bloom transition.

### Active: phosphor energize flash
On press, a `phosphor-energize` keyframe fires (150ms). Brightness flashes
to 1.4x, then holds at 1.08x while the button is held. The scanline
crawl overlay continues independently.

### Release: power-on impulse
On mouse-up, properties snap back with a 600ms spring curve:
`cubic-bezier(0.8, -0.5, 0.2, 1.4)`. The negative p2 makes a brief
undershoot (dips cold), and p4 > 1 overshoots past rest. The result is a damped
oscillation, like phosphor decay.

### Secondary: 2-layer bloom

The secondary button uses a softer version of the same effects:

| State | Behavior |
|-------|----------|
| **Hover** | 2-layer box-shadow (inner core + mid bloom), text-shadow glow, warmup flicker |
| **Active** | Intensified 2-layer glow, energize flash (no scanline) |
| **Release** | Gentler spring `cubic-bezier(0.5, -0.2, 0.2, 1.2)` over 400ms |

### Ghost: 1-layer bloom

The ghost button uses the lightest version:

| State | Behavior |
|-------|----------|
| **Hover** | 1-layer box-shadow (inner core only), text-shadow glow, fast warmup (200ms) |
| **Active** | Intensified 1-layer glow, energize flash (no scanline) |
| **Release** | Subtle spring `cubic-bezier(0.5, -0.1, 0.2, 1.1)` over 300ms |

### Link: text glow only

Link buttons get only a `text-shadow` glow on hover, with no box-shadow bloom
or spring easing. This keeps them light enough for inline use.

## Accessibility

- **Focus visible**: 2px solid outline with 2px offset, using `--color-semantic-border-focus`
- **High contrast**: Border widens to 3px via `prefers-contrast: high`
- **Reduced motion**: All transitions, animations, and filters disabled via `prefers-reduced-motion: reduce`
- **ARIA**: `aria-disabled` set when disabled or loading
- **Keyboard**: Full keyboard navigation with visible focus ring

## Form usage

Supports `type="submit"`, `type="reset"`, and `type="button"`:

```tsx
<form>
  <Button type="submit" variant="primary">Submit</Button>
  <Button type="reset" variant="secondary">Reset</Button>
  <Button type="button" variant="ghost">Cancel</Button>
</form>
```
