# RetroEffects

Full-screen CRT monitor overlay with scanlines, glow vignette, flicker, and phosphor bloom.

RetroEffects is a fixed-position overlay that layers CRT visual effects over your
application. Each effect layer can be toggled on its own. Power on/off animations mimic
a CRT monitor warming up and shutting down.

> **Interactive demos**: See the [RetroEffects stories](/story/components-retroeffects--default) for live interactive examples.

## Effect layers

| Layer | Default | Description |
|-------|---------|-------------|
| `scanlines` | On | Horizontal line pattern scrolling at 9s/cycle via `mix-blend-mode: screen` |
| `glow` | On | Radial vignette darkening edges, simulating phosphor falloff |
| `flicker` | On | Subtle opacity oscillation at 2Hz (WCAG 2.3.1 compliant, under 3Hz threshold) |
| `bloom` | Off | Soft inner glow simulating CRT halation (opt-in for performance) |

```tsx
{/* All default effects */}
<RetroEffects />

{/* Selective layers */}
<RetroEffects scanlines glow flicker={false} bloom />

{/* Minimal — scanlines only */}
<RetroEffects glow={false} flicker={false} />
```

## Intensity

The `intensity` prop (0-1) scales all effect opacities proportionally via the
`--retro-intensity` CSS custom property:

```tsx
<RetroEffects intensity={0.5} />  {/* Half strength */}
<RetroEffects intensity={0.2} />  {/* Subtle hint */}
```

## Power animations

Toggle `powered` to trigger CRT power on/off animations:

### Power on (600ms ease-out)
Horizontal line expands to full screen, like a CRT warming up from cold.

### Power off (400ms ease-in)
Screen collapses to a horizontal line, then disappears, like a CRT shutting down.

```tsx
const [powered, setPowered] = useState(true);

<RetroEffects
  powered={powered}
  onPowerOn={() => console.log('CRT warm')}
  onPowerOff={() => console.log('CRT cold')}
  onPowerStateChange={(state) => console.log(state)}
/>
```

### Power state machine

The component tracks four states: `on`, `powering-on`, `powering-off`, `off`.
The `onPowerStateChange` callback fires on each transition. Children are hidden
when fully `off`.

## Accessibility

- **ARIA hidden**: Entire component is `aria-hidden="true"` (decorative)
- **Pointer events**: Set to `none`, so effects never block interaction
- **Flicker safety**: Oscillation at 2Hz, well under the WCAG 2.3.1 three-flash threshold
- **High contrast**: Entire component is `display: none` via `prefers-contrast: high`
- **Reduced motion**: All animations disabled. Power transitions replaced with opacity fades (0.2s off, 0.3s on) via `prefers-reduced-motion: reduce`

## API reference

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `scanlines` | `boolean` | `true` | Enable scanline overlay |
| `glow` | `boolean` | `true` | Enable vignette glow |
| `flicker` | `boolean` | `true` | Enable CRT flicker |
| `bloom` | `boolean` | `false` | Enable phosphor bloom (opt-in) |
| `powered` | `boolean` | `true` | CRT power state (animates transitions) |
| `intensity` | `number` | `1` | Effect intensity (0-1) |
| `onPowerStateChange` | `(state: PowerState) => void` | — | Fires on power state transitions |
| `onPowerOn` | `() => void` | — | Fires when power-on animation completes |
| `onPowerOff` | `() => void` | — | Fires when power-off animation completes |
| `className` | `string` | `''` | Additional CSS classes |

### PowerState type

```ts
type PowerState = 'on' | 'powering-on' | 'powering-off' | 'off';
```
