# FilterBar

Multi-select toggle toolbar for faceted filtering.

FilterBar renders a horizontal row of toggle buttons following the WAI-ARIA toolbar
pattern with roving tabindex. Users can activate multiple filters simultaneously.
Designed for filter UIs in Lifelines timeline and content management views.

> **Interactive demos**: See the [FilterBar stories](/story/components-filterbar--default) for live interactive examples.

## Basic usage

```tsx
import { FilterBar } from 'eidotter';

const items = [
  { id: 'all', label: 'All' },
  { id: 'photos', label: 'Photos' },
  { id: 'notes', label: 'Notes' },
];

<FilterBar
  items={items}
  activeIds={['all']}
  onToggle={(id) => toggleFilter(id)}
/>
```

## Keyboard navigation

FilterBar implements roving tabindex per WAI-ARIA toolbar pattern:

| Key | Action |
|-----|--------|
| Arrow Right / Down | Move focus to next item |
| Arrow Left / Up | Move focus to previous item |
| Home | Move focus to first item |
| End | Move focus to last item |
| Enter / Space | Toggle active state |

Only the focused item has `tabIndex={0}`; all others have `tabIndex={-1}`.
Tab enters the toolbar, arrows move within it, and Tab exits.

## Accessibility

- **Role**: `role="toolbar"` on container with `aria-label`
- **Items**: `role="button"` with `aria-pressed` for toggle state
- **Roving tabindex**: Single tab stop with arrow key navigation
- **High contrast**: 2px borders, no glow
- **Reduced motion**: Transitions disabled

## API reference

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `items` | `FilterBarItem[]` | — | Array of `{ id, label }` toggle items |
| `activeIds` | `string[]` | `[]` | Currently active item IDs |
| `onToggle` | `(id: string) => void` | — | Called when an item is toggled |
| `size` | `'small' \| 'medium'` | `'medium'` | Button dimensions |
| `className` | `string` | `''` | Additional CSS classes |
| `aria-label` | `string` | — | Accessible toolbar label |

### FilterBarItem

```ts
interface FilterBarItem {
  id: string;
  label: string;
}
```
